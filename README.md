# دكاني — نظام إدارة البقالة 🧺

تطبيق **فلتر (Flutter)** لإدارة البقالة والمتاجر الصغيرة — إدارة المنتجات والمخزون والموردين وتواريخ الصلاحية.
التطبيق **ليس** لنقاط البيع (POS): لا يوجد كاشير أو فواتير بيع، بل نظام متابعة للمخزون.

> تطبيق عربي كامل (RTL)، يعمل **بدون إنترنت**، وبياناته محفوظة محلياً على الجهاز (SQLite).

## ✨ المميزات

| القسم | التفاصيل |
|---|---|
| 🏠 لوحة التحكم | إحصائيات (عدد المنتجات، قيمة المخزون، الفئات، الموردون)، تنبيهات المخزون المنخفض، حالات الصلاحية، وأحدث الحركات |
| 📦 المنتجات | اسم، باركود، فئة، مورد، وحدة قياس، سعر تكلفة/بيع، حد أدنى، كمية، ملاحظات — مع بحث وفلاتر وترتيب |
| 📷 مسح الباركود | مسح بالكاميرا: يفتح المنتج مباشرة، أو يعبّئ باركود منتج جديد تلقائياً |
| 🔔 تنبيهات الصلاحية | إشعار يومي مجدول (مع اختيار الوقت) بالدفعات المنتهية والقريبة من الانتهاء |
| ⚠️ تنبيه انخفاض المخزون | إشعار فوري عند نزول منتج عن الحد الأدنى بعد أي حركة خروج |
| 🌗 مظهر مرن | وضع فاتح / داكن / حسب النظام |
| 🔄 حركات المخزون | استلام من مورد (مع سعر التكلفة وتاريخ الصلاحية)، تسوية زيادة/نقص، هالك/تالف، مرتجع للمورد — بخصم تلقائي من الدفعات (FIFO) |
| 📋 جرد المخزون | تدوين الكمية الفعلية لكل منتج وتطبيق الفروقات تلقائياً كتسويات دفعة واحدة |
| 🛒 قائمة الطلب المقترحة | أصناف تحتاج إعادة طلب مجمعة حسب المورد مع الكمية المقترحة وتصدير CSV |
| ⏰ تواريخ الصلاحية | دفعات (Batch) لكل منتج، تنبيهات المنتهي وما ينتهي خلال 30 يوماً، زر إتلاف مباشر للدفعة |
| 📊 التقارير | قيمة المخزون حسب الفئة، إجمالي الاستلامات، قيمة الهالك، أعلى المنتجات قيمة، حركات آخر 30 يوم |
| 🏷️ الفئات | تنظيم المنتجات (خضار، ألبان، مشروبات...) |
| 🚚 الموردون | اسم، هاتف، عنوان، ملاحظات |
| 💰 حسابات الموردين | رصيد مستحق تلقائي (استلامات − مدفوعات)، تسجيل دفعات، سجل كامل لكل مورد |
| 💾 نسخ احتياطي | إنشاء / مشاركة / استعادة / حذف نسخ احتياطية كاملة — بما فيها الاستعادة من ملف خارجي |
| 📤 تصدير CSV | مشاركة تقارير Excel/CSV: قائمة المنتجات، سجل الحركات، تقرير الصلاحية |
| ❓ دليل الاستخدام | صفحة مساعدة داخل التطبيق تشرح كل الأقسام خطوة بخطوة |
| ⚙️ الإعدادات | اسم المتجر، رمز العملة، بيانات تجريبية للتجربة السريعة |

## 🏗️ هيكل المشروع

```
lib/
├── main.dart                  # نقطة الدخول (RTL + عربي)
├── models/                    # النماذج: منتج، فئة، مورد، دفعة، حركة
├── db/database.dart           # SQLite: الجداول والعمليات
├── state/app_state.dart       # إدارة الحالة (Provider)
├── screens/                   # الشاشات
├── widgets/                   # مكونات مشتركة
└── utils/format.dart          # تنسيق الأرقام والتواريخ
android/                       # مشروع أندرويد كامل جاهز للبناء
workflows/build-apk.yml        # ملف بناء APK تلقائي (GitHub Actions)
```

## 📲 طريقة الحصول على ملف APK

### الطريقة 1: GitHub Actions (الأسهل — بدون تثبيت أي شيء)
1. انقل ملف `workflows/build-apk.yml` إلى `.github/workflows/build-apk.yml` داخل المستودع.
2. ادفع التغيير (`git push`). أو من تبويب **Actions ← Build APK ← Run workflow**.
3. انتظر انتهاء البناء (~5-10 دقائق) ثم حمّل ملف `dokkan-apk` من **Artifacts**.
4. ثبّت الـ APK على هاتفك (فعّل "السماح بالتثبيت من مصادر خارجية").

### الطريقة 2: البناء محلياً
تحتاج: [Flutter SDK](https://docs.flutter.dev/get-started/install) (الإصدار 3.24 أو أحدث) + Android Studio/SDK.

```bash
flutter pub get
flutter build apk --release
# الناتج: build/app/outputs/flutter-apk/app-release.apk
```

> نسخة الإصدار موقّعة بمفتاح التطوير (debug key) تلقائياً، لذا التطبيق قابل للتثبيت مباشرة.

## 🗄️ قاعدة البيانات

- الملف: `dokkan_pro.db` داخل مجلد بيانات التطبيق.
- الجداول: `categories`، `suppliers`، `products`، `batches` (دفعات الصلاحية)، `stock_movements`، `settings`.
- حركات الاستلام تضيف دفعة جديدة مع تاريخ الصلاحية؛ أي حركة خروج تخصم من الأقدم أولاً (FIFO).

## 📦 الحزم المستخدمة
`sqflite` (قاعدة البيانات) • `provider` (إدارة الحالة) • `intl` (تواريخ عربية) • `mobile_scanner` (مسح الباركود) • `flutter_local_notifications` + `timezone` (تنبيه الصلاحية اليومي) • `path_provider` + `share_plus` (تصدير CSV ومشاركة النسخ الاحتياطية) • `file_picker` (استعادة من ملف) • `path`
